# 小红书发布

## 发布前（全部满足才开始）

0. 第三方事实核查（必过）：成稿（正文 + 每张图上的文字）定稿后、交用户确认前，交给没参与写稿的一方对照一手来源逐条核对机制描述、数字及其出处、人名和限制条件，回一份「必须改 / 不精确 / 没问题」清单；必须改和不精确的全部改完、重跑自查，再把核查结论和改动一起交用户确认。核查人是谁见用户的偏好层（如有）。没过核查不发。
1. 用户已对这一版标题、正文、图片明确点头（偏好层里写明的免确认例外除外）。
2. 文案自查 PASS：`python3 <social-copywriting>/scripts/lint_copy.py --title title.txt --body body.txt --tags tags.txt --profile <偏好层>/SKILL.md`（标题 ≤20 字；正文 + 话题 ≤1000 字，超了平台会拦）。写长文：正文加 `--longform` 查（编辑器标题 ≤64，正文不限字数），发布页的短标题另用默认模式查 ≤20。
3. 图片自查 PASS：`python3 <xhs-card-design>/scripts/check_cards.py cards/*.png`。交图给用户时附上这次的输出行（横带占比、网格不合格区）；没跑或没 PASS，不说「没有留白」「可以发」。
4. 用户点头后又改过稿：改完重跑 2、3，并把改动告诉用户。
5. 用户或核查说「不用提 / 删掉」某句：必须改 `body.txt`/`title.txt`（以及图上的文字），再用搜索确认无残留后才能发；不能只把该条从修改清单里划掉。改完重跑 2、3。

## 发布步骤

1. 打开 creator.xiaohongshu.com →「发布笔记」→「上传图文」。
2. **出现登录页、二维码、短信验证码、滑块验证就停**，不绕过。但别马上说「登录失效」：发布页加载慢、跳转或报错也会落到登录页。先单独打开 creator.xiaohongshu.com 首页，刷新一次；首页能看到账号名或笔记数据，就是登录着的，回到发布页重试。只有首页也要求登录、读不到任何账号数据，才告诉用户需要他扫码登录，并附上首页截图。页面空白先刷新一次，仍空白就报告。
3. 按 `01.png → 0N.png` 顺序上传，核对缩略图顺序。
4. 填标题（与 `title.txt` 一字不差）。
5. 粘贴正文（`body.txt`）。
6. 话题：在正文末尾逐个输入 `#关键词`，等联想下拉出现后点选。点选成功的话题显示为**蓝色**；黑色纯文本的 `#词` 无效，删掉重选，换一个联想里有的词。
7. 选合集：按偏好层的合集对照表选对应合集。
8. 发布前截图核对：图片顺序、标题、正文末尾、每个话题都是蓝色、合集名。
9. 点发布。

## 写长文

长文先在编辑器排版，再进发布设置页。以下限制和坑点来自实际发布。

1. 入口：「发布笔记」→「写长文」→ 新的创作。编辑器标题 ≤64 字，正文没有 1000 字限制，可插图。
2. 贴入正文后点「一键排版」选模板。**先定模板，再填发布设置**：在发布设置页换模板或点「返回」，标题、描述、话题、合集会被重置，已加的图片也会丢，只能从头重填。不要把封面图插进长文正文；封面只在发布设置页替换模板第 1 页。
3. 「下一步」进入发布设置页，依次处理：
   - **标题框 ≤20 字**，比编辑器的 64 字短。提前准备一个 ≤20 字的短标题（同样按半角两个算一个字）。
   - **图片**：模板（如「清晰明朗」）会自动生成一张白底「首页」（抠图人像 + 大标题）。用自己的封面时，只在发布设置页点「+」上传封面并放到第一张，再删掉模板首页，只保留一张照片页；模板的第一张正文配图也可以替换。**不要把封面图插进长文正文**，否则模板标题页里会再套一张封面，变成「封面里套封面」。封面要求见 `xhs-card-design` §1。
   - **模板自动生成的正文页不能删**：长文的正文就是模板排出来的那十几张正文页。曾有一次把模板图全删、只留自己的 5 张卡片，发布后笔记变成「5 图 + 185 字描述」，长文正文整篇丢失。只替换模板首页为自己的封面，正文页全部保留；自己的导览卡片如需加，就插到正文页之后，不能顶替正文页。发布前数一下图片数（应约为 1 封面 + 全部正文页 + 自加卡片）。
   - **调顺序不靠拖拽**：拖拽经常不生效。位置不对的图先删掉，再按顺序重新上传。
   - **放大核对缩略图**：发布前放大「图片编辑」缩略图（或看右侧「封面预览」），逐张确认顺序；第一张就是要用的封面，确认不是「封面里套封面」。
   - 描述和话题：话题同样要点选成蓝色（见「发布步骤」第 6 步）。
   - 合集：按偏好层的合集对照表放进对应的现有合集；新建合集时平台要求上传合集封面。
4. 发布前截图核对：首图、图片顺序、短标题、描述末尾、话题全蓝、合集名；首图不是「封面里套封面」。

## 发布后

- 打开笔记页再核对一遍，记下笔记链接或 ID。长文刚发布时可能暂时不出现在笔记管理的「已发布」「审核中」分类里，先在「全部」里找；拿不到 ID 就在已发清单里标「待确认」，稍后回查补上。
- 回写合集进度文件（路径见偏好层）：编号、标题、发布时间（带时区）、风格。
- 在全平台已发清单（路径见偏好层）追加一行：日期、平台、合集、标题、核心选题、关键词、链接。
- 需要在评论区补充说明时，按用户给的原话发，不自拟。

## 不做

- 用户没确认的版本不发；发布被叫停后不用旧版本继续发。
- 不在发布页里临时改文案；要改回到源文件，改完重跑自查。
- 不把已说「不用提 / 删掉」的句子留在源文件里就发。
- 不把封面图插进长文正文。
