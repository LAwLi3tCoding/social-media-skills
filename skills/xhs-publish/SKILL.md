# 小红书发布

## 发布前（全部满足才开始）

0. 第三方事实核查（必过）：成稿（正文 + 每张图上的文字）定稿后、交用户确认前，交给没参与写稿的一方对照一手来源逐条核对机制描述、数字及其出处、人名和限制条件，回一份「必须改 / 不精确 / 没问题」清单；必须改和不精确的全部改完、重跑自查，再把核查结论和改动一起交用户确认。核查人是谁见用户的偏好层（如已安装的 `content-profile`）。没过核查不发。
1. 用户已对这一版标题、正文、图片明确点头（偏好层里写明的免确认例外除外）。
2. 文案自查 PASS：`python3 <social-copywriting>/scripts/lint_copy.py --title title.txt --body body.txt --tags tags.txt --profile <偏好层>/SKILL.md`（标题 ≤20 字；正文 + 话题 ≤1000 字，超了平台会拦）。
3. 图片自查 PASS：`python3 <xhs-card-design>/scripts/check_cards.py cards/*.png`。交图给用户时附上这次的输出行（横带占比、网格不合格区）；没跑或没 PASS，不说「没有留白」「可以发」。
4. 用户点头后又改过稿：改完重跑 2、3，并把改动告诉用户。

## 发布步骤

1. 打开 creator.xiaohongshu.com →「发布笔记」→「上传图文」。
2. **出现登录页、二维码、短信验证码、滑块验证就停**，不绕过。但别马上说「登录失效」：发布页加载慢、跳转或报错也会落到登录页。先单独打开 creator.xiaohongshu.com 首页，刷新一次；首页能看到账号名或笔记数据，就是登录着的，回到发布页重试。只有首页也要求登录、读不到任何账号数据，才告诉用户需要他扫码登录，并附上首页截图。页面空白先刷新一次，仍空白就报告。
3. 按 `01.png → 0N.png` 顺序上传，核对缩略图顺序。
4. 填标题（与 `title.txt` 一字不差）。
5. 粘贴正文（`body.txt`）。
6. 话题：在正文末尾逐个输入 `#关键词`，等联想下拉出现后点选。点选成功的话题显示为**蓝色**；黑色纯文本的 `#词` 无效，删掉重选，换一个联想里有的词。
7. 选合集：按偏好层的合集对照表选对应合集。
8. 发布前截图核对：图片顺序、标题、正文末尾、每个话题都是蓝色、合集名。
9. 点发布。

## 发布后

- 打开笔记页再核对一遍，记下笔记链接或 ID。
- 回写合集进度文件（路径见偏好层）：编号、标题、发布时间（带时区）、风格。
- 在全平台已发清单（路径见偏好层）追加一行：日期、平台、合集、标题、核心选题、关键词、链接。
- 需要在评论区补充说明时，按用户给的原话发，不自拟。

## 不做

- 用户没确认的版本不发；发布被叫停后不用旧版本继续发。
- 不在发布页里临时改文案；要改回到源文件，改完重跑自查。
